## AI Assistance and Validation Declaration

### 1. AI Assistance

AI tools were used during the development of the SHIORI Café project to support the team in the following activities:

- Providing guidance on project documentation and organization.
- Assisting with writing and improving technical documentation.
- Providing explanations and suggestions for programming and troubleshooting.
- Helping organize GitHub repository contributions and workflow instructions.

AI-generated suggestions were treated as references and were reviewed by the team before being included in the project.

### 2. Validation Activities

The team is responsible for reviewing and validating all project outputs. Validation activities include:

- Reviewing AI-assisted content for accuracy and relevance.
- Checking documentation against the actual features of the application.
- Reviewing code changes before committing them to GitHub.
- Checking database configurations and ensuring that database instructions match the current project setup.
- Testing applicable application features and correcting identified issues.

### 3. Responsibility Statement

The team acknowledges the use of AI assistance and takes responsibility for the accuracy, functionality, security, and quality of the final project. AI tools do not replace the team's own understanding, implementation, testing, and decision-making.
